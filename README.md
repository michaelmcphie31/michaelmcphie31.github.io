# Body of Works Fitness Website

A fast static website for an all-natural, holistic longevity coach.

## Pages

- `index.html`
- `about.html`
- `services.html`
- `testimonials.html`
- `contact.html`

## Structure

- `css/styles.css`: shared responsive styling
- `js/main.js`: mobile navigation and header behavior
- `assets/images/`: optimized local WebP visuals
- `assets/favicon.svg`: site icon

Open `index.html` in a browser to view the site. No build step is required.

Each rendered image placement uses a unique local WebP asset.
